# TickleApps Website

Official website for **TickleApps** — building smart mobile apps like NutriScan for a global audience.

This is a **pure static website** designed for professional hosting (e.g., Hostinger). It uses a clean, folder-based routing architecture for SEO and user experience.

## ✨ Features

- **Premium SaaS Aesthetic**: Modern, clean, and trustworthy design.
- **Clean URLs**: No `.html` extensions. Navigating to `/about/` serves `about/index.html`.
- **Static Architecture**: Compatible with any static file hosting service.
- **EmailJS Integration**: Functional contact form without a backend.
- **AdSense Ready**: Optimized slots and compliant Privacy Policy.
- **SEO Optimized**: Meta tags, Open Graph, and semantic markup.

## 📁 Folder Structure

## 🚀 Deployment (Hostinger)

1. Ensure the `public` directory contains all your pages and assets.
2. Zip the contents of the `public` folder.
3. Upload and extract to the `public_html` directory in your Hostinger File Manager.
4. Set up your domain to point to this directory.

## 📨 Contact Form (EmailJS)

1. Sign up at [EmailJS](https://www.emailjs.com/).
2. Create an Email Service and an Email Template.
3. Update `assets/js/contact.js` with your specific credentials.

## 💰 AdSense Integration

- Placeholder slots are marked with `<!-- GOOGLE ADSENSE PLACEHOLDER -->`.
- The Privacy Policy is pre-written to meet AdSense compliance requirements.
